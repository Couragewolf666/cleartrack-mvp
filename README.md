# ClearTrack MVP

A lightweight compliance-document tracker inspired by the workflow of systems like Complio.

## Run it
Open `index.html` in any modern browser.

## Included
- Compliance dashboard
- Requirement statuses
- Expiration dates
- Completion statistics
- Status filters
- Add/delete requirements
- Mock document attachment
- Browser-local persistence via localStorage

## Important limitation
This prototype does not upload document contents anywhere. It stores only metadata and filenames in the browser.
